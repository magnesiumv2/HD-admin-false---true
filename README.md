## para que usar e como usar

Você deve utilizar um executor de exploits confiável pela recomendação que roda no lado do **Client** e não deve ser executado pelo servidor.

use para tirar skins inapropriadas do jogo específico pois o objetivo do painel é limpar e moderar já que a moderação oficial não cuida disso para os jogadores, temos nós que cuidar.

## Comandos e em quais situações

- ;kill - [Player] utilize em situações leves
- ;kick - [Player] utilize em situações mais cirúrgicas, mas cuidado, ele está na versão 1 e ele é tão agressivo que pode congestionar a rede de alguns jogadores
- ;jail - use para situações leves apenas para avisar
- ;bring - use para trazer o infrator para a sua frente para ficar de cara a cara com você
- ;punish [Player] - use em situações comuns apenas para punir o infrator, deixando a tela dele piscando preto e exibir a imagem
- ;persistentpunish [Player] - use para punir o infrator para evitar você causando spam no chat e para você descansar enquanto opera
- ;unpersistentpunish [Player] - use para parara punição persistente
- ;shutdown [Player] - use apenas quando tiver certeza absoluta se precisa executar um mass kick
- ;allow [Player] - use para contratar algum jogador para te ajudar com a situação para dar privilégios de moderador local
- ;unallow [Player] -use para remover os privilégios de moderador local

  use o painel de forma consciente e não use para arruinar o servidor
